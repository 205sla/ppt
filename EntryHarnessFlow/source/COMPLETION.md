## 조작

- 기본 조작: 다음 페이지는 스페이스·→·↓·PageDown, 이전 페이지는 ←·↑·Shift+스페이스·PageUp. Home/End·아래 이동 버튼·좌우 밀기도 유지합니다.
- 전시 재생: 오른쪽 위 **자동재생 켜기** 버튼. 현재 장면부터 이어 재생하며, 각 장의 완성 장면과 표지·정리 장은 8초간 유지한 뒤 다음 페이지로 넘어갑니다. 마지막 장 뒤에는 표지로 돌아갑니다.
- 전시 중 첫 **Space** 또는 **자동재생 끄기**는 페이지를 유지하며 수동 조작으로 전환합니다. 다시 켜기 버튼을 누를 때까지 페이지는 자동으로 넘어가지 않습니다. 수동 모드의 장면 자동 진행·페이지 키·단계 버튼은 기존 그대로입니다.
- 장면 단계: 페이지에 들어오면 1단계부터 4초 간격으로 자동 재생하고 마지막 단계에서 멈춥니다. 뒤에서 돌아와도 처음부터 재생합니다.
- 슬라이드 오른쪽 아래 ‹ › 버튼으로 단계를 직접 고를 수 있고, 선택한 단계부터 자동 재생을 이어 갑니다. ↺는 처음부터 다시 재생합니다. 클릭·Enter로 버튼을 조작하며, 스페이스는 버튼에 포커스가 있어도 다음 페이지로 이동합니다.
- 탭을 숨기거나 인쇄할 때 자동 재생을 멈춥니다. 돌아오면 현재 단계부터 이어 갑니다. 움직임 줄이기 설정에서는 마지막 장면을 바로 보여 줍니다. PDF에도 마지막 장면이 실립니다.
- N: 발표자 노트(모든 장), F: 전체 화면. 전시 재생 버튼은 전체 화면에서도 표시합니다.
- 하단 이동 버튼·단계 버튼·PDF 버튼·링크에 포커스가 남아도 페이지 이동 키가 한 번만 작동합니다. Enter·Tab·입력 요소의 키 조작은 유지합니다.

## 남은 제한

- 무선 프레젠터의 PageDown은 슬라이드를 넘깁니다. 장면 단계는 자동 재생하며 화면 버튼으로 직접 고를 수도 있습니다.
- 휴대폰 크기에서는 공통 이동 버튼이 맨 아래 설명 일부를 덮을 수 있습니다(공통 기능 동작).
- 문구를 바꾸면 `subset-fonts.py`로 글꼴을 다시 만들어야 합니다. 빠진 글자는 `qa.mjs`가 알려 줍니다.
