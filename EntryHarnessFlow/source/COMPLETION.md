## 조작

- 슬라이드: ← → · 스페이스 · PageUp/PageDown · Home/End · 아래 이동 버튼 · 좌우 밀기(공통 기능). 자동 전환은 없습니다.
- 장면 단계: 슬라이드 오른쪽 아래 ‹ › 버튼 또는 ↓ ↑ 키. ↺는 처음부터 다시 재생합니다. 단계 조작은 슬라이드를 넘기지 않습니다.
- 앞에서 들어오면 1단계, 뒤 장에서 돌아오면 완성 단계로 보입니다. PDF에는 완성 단계가 실립니다.
- N: 발표자 노트(모든 장), F: 전체 화면.
- 하단 이동 버튼·단계 버튼·PDF 버튼·링크를 마우스나 키보드로 누른 뒤에도 ← → PageUp/PageDown Home End N F가 바로 작동합니다. 이 자료의 `deck.js`가 버튼·링크에서 온 이 키만 처리하고, 스페이스·Enter·Tab은 버튼 기본 동작 그대로 둡니다(포커스는 옮기지 않음).

## 눈으로 확인한 범위

- 세 화면 크기에서 12장의 46개 단계 화면 전부(`source/preview.mjs`), PDF 12쪽 전체와 2쪽 원본 해상도.

## 남은 제한

- 무선 프레젠터의 PageDown은 슬라이드를 넘깁니다. 장면 단계는 화면 버튼이나 ↓ ↑ 키로 넘깁니다.
- 휴대폰 크기에서는 공통 이동 버튼이 맨 아래 설명 일부를 덮을 수 있습니다(공통 기능 동작).
- 문구를 바꾸면 `subset-fonts.py`로 글꼴을 다시 만들어야 합니다. 빠진 글자는 `qa.mjs`가 알려 줍니다.
