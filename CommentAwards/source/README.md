# 좋은 댓글 시상식

12장으로 구성한 동적 HTML 발표다. 2026-09-20 수집한 원댓글 71개와 답글 29개를 검토해 김규민·윤도경·신지안을 선정하고 이름·선정 이유·대표 댓글·작품 제목을 채웠다. 세 사람 모두 같은 상이며 소개 순서는 등수가 아니다. 선정 근거와 댓글 출처는 `selection.md`에 기록했다.

## 실행

저장소 루트에서 `npm.cmd run serve`를 실행하고 `http://127.0.0.1:4173/CommentAwards/`를 연다. 또는 `CommentAwards/index.html`을 Chrome이나 Edge에서 직접 열어도 된다.

‘발표 시작’을 한 번 누르면 효과음과 함께 자동으로 진행한다. 브라우저의 소리 재생 정책 때문에 첫 시작은 클릭이 필요하다. 무음으로 즉시 자동 시작하려면 주소 뒤에 `?autoplay=1`을 붙인다. 전체 화면은 별도 버튼 또는 F로 켠다.

기본 진행은 표지 6초 → 도입 8초 → (공개 전 6초 → 이름 공개 12초 → 대표 댓글 14초) × 3명 → 마지막 축하 화면 유지다. 마지막 화면까지 약 1분 50초가 걸리고 자동으로 반복하지 않는다.

- SPACE: 일시정지 / 계속 재생
- ← / →: 이전 / 다음 장면
- R: 처음부터 자동 재생
- M: 효과음 켜기 / 끄기
- E: 내용 입력
- F: 전체 화면
- N: 발표자 노트

다른 탭으로 이동하면 자동으로 일시정지한다. 운영체제의 동작 줄이기 설정을 존중한다. 짧은 음색·카운트다운·축하 효과음은 Web Audio로 자체 합성하며 외부 음원이나 네트워크 연결이 필요하지 않다.

## 내용 조정

화면 아래의 ‘내용 입력’에서 세 사람의 닉네임, 선정 이유, 대표 댓글, 작품 제목을 조정하고 적용한다. 이 브라우저에만 저장되며 다음에 같은 주소를 열면 다시 사용한다. 웹사이트의 배포 원본을 바꾸지는 않는다. 입력 창은 열기 전까지 화면에 나타나지 않는다.

‘내용 파일 저장’으로 JSON을 내려받고 다른 컴퓨터에서 ‘내용 불러오기’를 사용하면 옮길 수 있다. 배포 내용을 바꾸려면 `content.js`의 `winners`를 수정하고 `node CommentAwards/source/build-html.mjs`로 HTML을 재생성한다. `revision`이 같은 브라우저 저장값은 파일 기본값보다 우선한다. 새 발표의 기본값을 확실히 적용하려면 `revision`을 올린다.

공개 시간과 댓글 화면 시간도 입력 창에서 바꿀 수 있다. 닉네임은 24자, 선정 이유는 90자, 댓글은 220자, 작품 제목은 60자 이내로 입력한다. 최대 길이도 별도로 화면 검수한다.

## 보관과 확인

사용자 요청에 따라 `decks.json`에 `pdf: false`를 설정했다. PDF 파일과 다운로드 버튼은 생성·배포하지 않으며, 나머지 자료의 기존 PDF 처리는 유지한다. 실제 선정 내용으로 채운 뒤 공개 상태로 전환했다.

`npm.cmd run qa -- CommentAwards`와 독립 검사 `node CommentAwards/source/qa.mjs`에서 자동 재생·카운트다운·효과음·입력·긴 문장·모바일을 검수한다. 원본은 `index.html`, `styles.css`, `deck.js`, `content.js`, `assets/stage-gold.png`다. 배포 절차는 전체 `npm.cmd test`, `npm.cmd run build`, `npm.cmd run qa`를 통과한 뒤 `main` 푸시와 GitHub Pages 완료를 확인한다.

배경 제작 방식과 프롬프트는 `source/visual-source.md`에 기록했다.
