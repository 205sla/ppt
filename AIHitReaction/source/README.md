# AIHitReaction

사용자 제공 `AI_Hit_Reaction_Research_Plan.md`를 분석한 독립 주제 검토 페이지다. 원문과 조사 기록은 학기 문서 폴더의 `임시검토/20261002_AI피격반응/`에 보관한다.

2026-10-02 사용자가 PDF를 미루고 배포를 먼저 요청하여 `pdf: false`로 공개한다. PDF 생성·다운로드 버튼은 포함하지 않는다.

16개 장. 자동재생 도식은 학습 결과나 엔진 시연이 아니다. 입력 슬라이더를 조작하면 해당 자동재생이 멈추며 다시 시작할 수 있다. 전역 일시정지·감소된 모션 설정·비활성 탭·인쇄 상태를 존중한다. 장은 자동 전환하지 않는다.

연구 후보 상태, 원안과 추가 제안, 실측 전 상태를 유지한다. 선행연구 링크는 마지막 장과 해당 장에 함께 제공한다. 공통 코드 변경 없이 페이지 내부에서 읽기 레이아웃을 구성했다.

검수: `npm.cmd run qa -- AIHitReaction`. 배포 전 전체 빌드와 공개 URL 확인. 사이트의 기존 PDF 자료는 해당 자료실의 일반 빌드 규칙을 따른다.
