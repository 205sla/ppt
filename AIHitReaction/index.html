03

왜 연구할 가치가 있나

클립·물리·학습은
서로 다른 비용을 가집니다

접근반응을 만드는 방법살펴볼 점
미리 만든 애니메이션조건에 맞는 클립을 선택하고 혼합제작 부담, 조건 사이의 변화, 반복감
물리 기반 반응관절·충격·동작 추종으로 매번 계산물리 설정과 안정성, 캐릭터 수별 계산 비용
학습한 자세 보정시뮬레이션 사례에서 배운 보정값을 추론학습 범위 밖의 오류, 품질과 실행 비용

공정한 비교에는 보간 방식도 필요합니다

기존 애니메이션도 블렌딩과 절차적 보정을 사용할 수 있습니다. 단순한 앞·뒤·좌·우 선택만 상대하지 않고, 같은 데이터의 이웃 샘플 보간도 비교합니다.

근거: Neural Animation Layering · SIGGRAPH 2021 · Epic · Physical Animation

클립 방식의 경우의 수가 증가한다는 원안의 문제의식은 유효하지만 기존 기법이 모두 이산 선택만 한다고 설명하면 과장이다. 신경망이 물리보다 빠르다는 결론도 실행 전에는 낼 수 없다.

이번 프로젝트의 연구 단위

통제한 피격 조건에서 물리 교사의 자세 차이를 작은 MLP로 학습하고, 보간·물리 실행과 품질 및 비용을 비교합니다. 새로운 범용 물리 엔진이나 최초의 신경망 애니메이션을 주장하지 않습니다.

근거: Neural Animation Layering · SIGGRAPH 2021 · DReCon · SIGGRAPH Asia 2019 · PDP · SIGGRAPH Asia 2024 · GPC · SIGGRAPH 2026

각 논문은 서로 다른 문제와 학습 방식을 다룬다. 특히 DReCon·PDP·GPC는 물리 제어를 포함하므로 최종 자세만 근사하는 이번 제안과 동일한 시스템이 아니다. 전체 재현과 원 논문 대비 우월성은 주장하지 않는다.

연구 설계

학습할 때 물리로 만들고,
실행할 때 보정값을 예측합니다

학습 단계게임을 반복 실행하며 예시를 수집
01기본 동작 + 피격위치·방향·충격량을 지정
02물리 반응 생성애니메이션을 추종하는 물리 교사
03자세 차이 저장기본 자세와 반응 자세의 쌍
04지도학습작은 MLP가 차이를 예측
게임 실행 단계피격 반응에 필요한 부분을 대체
01입력 구성기본 자세·속도·피격·시간
02신경망 추론상체 관절 회전 보정
03애니메이션 결합관절 한계와 복귀 처리
04최종 출력필요한 접촉 보정 후 렌더링

게임의 충돌 감지와 이동 처리는 유지합니다. 대체 후보는 피격 반응을 만드는 골격 물리 계산입니다.

학습은 Python/PyTorch, 게임 실행은 UE 내부 추론을 우선 검토한다. 여기서 AI는 수치 입력을 수치 보정으로 바꾸는 작은 신경망이다. 언어모델이나 LLM 파인튜닝을 전제로 하지 않는다.

06

구현 가능성

상체의 짧은 단발 피격부터
성립 여부를 확인합니다

첫 실험 제안

한 캐릭터, 한 골격

  • Idle·Walk의 기본 동작
  • 가슴·양쪽 어깨 중심의 상체
  • 넘어지지 않는 범위의 단발 충격
  • 기본 동작을 유지하는 짧은 반응
  • 루트 이동과 하체는 기본 동작으로 유지

첫 검증 이후 확장

범위가 크게 늘어나는 조건

  • Run·공격 중 피격, 연속 피격
  • 넘어짐과 스스로 일어나기
  • 균형 회복을 위한 발 디딤
  • 다른 체형·골격·질량
  • 지형과 전신 접촉 변화

범위를 줄여도 남는 연구 질문

학습에 없는 중간 충격량·방향에서 보정이 이어지는지, 물리 반응의 품질을 어느 수준까지 유지하는지, 보간보다 나은 구간이 있는지 평가할 수 있습니다.

원안은 전신·Idle/Walk/Run을 제시하지만 10주 동안 데이터와 엔진 추론까지 완성하려면 단계 구분이 필요하다. 이 범위는 분석 제안이며 팀이 이미 합의하거나 구현한 사양이 아니다.

충격이 없던 기본 자세를 함께 저장해야 피격으로 생긴 변화만 분리할 수 있습니다.

  1. 물리 교사 조정질량·관절 한계·추종 강도·감쇠를 고정합니다.
  2. 조건별 전체 반응 기록피격 전부터 복귀까지 하나의 에피소드로 저장합니다.
  3. 불량 사례 검수관절 폭주·관통·복귀 실패를 태그하고 원인별로 관리합니다.
  4. 재현 정보 보관골격·물리 설정·클립·위상·시간 간격·시드·좌표계를 남깁니다.

물리 결과는 학습용 교사입니다

시뮬레이션이 만든 결과에도 부자연스러운 반응이 있을 수 있습니다. 교사와 닮은 정도와 사람이 보기에 자연스러운 정도를 별도로 평가합니다.

근거: Epic · Physical Animation

무작정 ragdoll을 기록하면 힘이 빠진 움직임을 그대로 학습할 수 있다. 물리 교사 품질이 연구의 첫 관문이다. 고정 시간 간격과 시드를 기록하더라도 엔진 환경을 넘어 완전한 결정성을 보장한다고 쓰지 않는다.

작은 회전 벡터 등 일관된 표현을 사용하고 유효한 회전으로 변환합니다.

ΔRt = fθ(기본 자세, 피격 시점 상태, 충격 조건, 경과 시간)

학습 입력과 게임 입력을 같게 만듭니다

게임에서 얻을 수 없는 교사의 미래 자세를 입력하지 않습니다. 매번 기본 자세에 보정하며, 이미 보정된 자세에 같은 차이를 반복해 더하지 않습니다.

MLP는 사전학습 언어모델을 미세조정하는 계획이 아니라 수집한 수치 데이터로 새 회귀 모델을 학습하는 기준선이다. 현재 기본 자세만으로 과거 충격 상태를 구분하기 어려우므로 피격 시점 상태와 위상을 저장한다. 모델 크기와 학습량은 예비 실험으로 정한다.

연구 설계

회전 보정과 접촉 제약을
분리해서 적용합니다

기본 자세 + 상체 보정결합 과정

기본 자세에서 보정을 시작합니다.

회전·복귀의 개념을 보여 주는 도식입니다.

Rfinal = Rbase · ΔRpred

회전은 행렬 곱이나 쿼터니언 합성으로 결합합니다. 좌표 값처럼 단순히 더하면 올바른 관절 회전을 보장할 수 없습니다.

관절 한계
허용 범위를 넘는 보정과 급격한 변화를 제한합니다.
복귀
교사의 복귀가 포함된 차이를 학습한다면 감쇠 곡선을 다시 곱하지 않습니다.
접촉 보정
IK는 발 위치 등을 맞추는 보조 수단입니다. 걷는 중 공중에 있는 발까지 고정하지 않습니다.

근거: Epic · Full-Body IK

설계 제안은 교사의 애니메이션 혼합 후·공통 IK 전 자세 차이를 타깃으로 삼는다. 이 경우 이미 포함된 시간 감쇠를 추론 뒤 중복 적용하지 않는다. 입력과 타깃 모두 같은 부모 관절 국소 좌표계를 사용하고 회전 곱 순서를 고정한다. IK는 동적 균형 제어기의 대체가 아니다.

시험무엇을 숨기는가해석
보간학습 범위 안의 중간 충격량·방향연속 조건 사이를 채울 수 있는가
조합 일반화보지 않은 방향 × 위치 × 동작 위상 조합익숙한 요소를 새 조합에 적용하는가
분포 밖 조건학습 범위 밖 충격량·부위 등오류가 커지는 경계와 대체 동작을 확인

프레임을 무작위로 섞으면 시험이 쉬워집니다

같은 피격의 이웃 프레임이 학습과 시험에 나뉘지 않도록 전체 에피소드·피격 조건 묶음으로 먼저 분리합니다. 정규화와 모델 선택은 학습·검증 데이터만 사용합니다.

100·300으로 학습하고 200을 예측하는 예는 보간이다. 이것만으로 다른 캐릭터나 모든 미지 상황으로 일반화한다고 결론 내릴 수 없다. 여러 클립이 있으면 클립 단위 홀드아웃도 별도 실험한다. 시험 그룹은 수집 전에 배정한다.

초기 연결 시험

작은 임시 모델의 같은 입력에 대해 Python과 UE 출력이 일치하는지 먼저 확인합니다. 이 단계는 피격 학습 성공과 구분합니다.

선택한 엔진 버전·플랫폼에서 모델 연산 지원과 패키지 실행을 확인한 뒤 데이터 수집 규모를 늘립니다.

측정에 포함할 비용

자세 추출, 입력 정리, 추론, 결과 전달, 관절 적용, IK까지 모두 포함합니다.

작은 모델에서는 GPU 전달·동기화 비용이 이득을 지울 수 있어 CPU부터 실측합니다.

근거: Epic · Neural Network Engine · Epic · NNERuntimeORT

Epic NNE는 CPU·GPU·RDG 인터페이스를 제공하며 현재 공식 문서는 Beta로 표기한다. CPU 우선은 이 작업의 설계 제안이다. 포즈를 임의 스레드에서 직접 읽거나 쓰지 않고 엔진 애니메이션 평가 단계와 메모리 수명을 맞춰야 한다. 실제 엔진 연결은 아직 하지 않았다.

12

검증 설계

같은 피격을 네 방식에 주고
품질과 비용을 함께 비교합니다

조건내용비교 목적
A · 클립 선택제작한 제한된 피격 클립을 조건별 선택일반적인 제작 방식의 기준
B · 이웃 샘플 보간학습용과 같은 기록 데이터에서 가까운 조건을 보간신경망 없이 연속 조건을 다루는 강한 기준
C · 물리 교사 실행고정한 물리 설정으로 반응 계산근사 대상의 품질·계산 비용
D · 학습 보정같은 데이터로 학습한 작은 MLP근사 오차와 실행 비용의 절충

공통 조건
동일 캐릭터·기본 클립·피격·하드웨어·품질 설정을 사용합니다. 적용 가능한 혼합·IK 설정을 맞추고 차이가 필요하면 기록합니다.

추가 확인
D의 IK 사용 전후, 입력에서 속도·피격 시점 정보를 뺀 조건을 비교해 어떤 요소가 효과를 냈는지 확인합니다.

A는 실제 사용 가능한 클립을 기준으로 하며 B와 D는 동일한 학습 데이터만 사용한다. C는 시험 조건에서도 실행해 참조 궤적을 만들 수 있지만 그 결과를 D의 훈련으로 누출하지 않는다. 반복 횟수와 허용 오차는 예비 실험 후 본 시험 전에 고정한다.

13

연구 설계

닮은 정도·자연스러움·속도를
각각 측정합니다

01

교사와의 차이

관절 회전 오차와 몸 기준 관절 위치 오차를 시간에 따라 기록합니다.

평균뿐 아니라 피격 직후 최대 오차와 실패 사례
02

동작 품질

접지 중 발 미끄러짐, 관통, 관절 한계 위반, 떨림, 복귀 실패를 셉니다.

교사 오차와 별개로, 조건명을 가린 영상 평가도 제안
03

실행 비용

추론 단독과 전체 반응 처리 시간의 p50·p95, 메모리, 프레임 시간을 기록합니다.

워밍업 후, 캐릭터 수를 바꾸며 측정

성공 판정은 “더 빠름” 한 문장으로 끝나지 않습니다

품질이 허용 범위에 남는 조건에서 비용이 줄었는지 확인합니다. 이득이 없다면 어느 조건에서 보간이나 물리 실행이 더 적합한지 실패 결과까지 정리합니다.

표본 수·품질 허용치·목표 장비·시간 예산은 예비 실험 후 고정할 항목입니다. 현재 실측 수치는 없습니다.

p50은 중앙값, p95는 95%의 관측값이 그 이하인 시간이다. 평균이 낮아도 드문 지연이 체감 품질을 해칠 수 있다. 자연스러움 평가에는 임의 순서와 동일 카메라·속도를 적용하고 평가자 수와 불확실성을 함께 보고한다.

14

일정 제안

데이터와 엔진 연결을
초반에 작게 검증합니다

기간할 일통과 기준
1주범위·좌표계 확정, 작은 ONNX 모델 왕복Python과 엔진 출력 대조, 패키지 실행 확인
2주피격 감지와 상체 물리 교사 조정부위·방향·충격량에 따른 안정적인 반응
3주기본/반응 자세 쌍 기록, 분리 규칙 설정같은 피격의 기록·재생과 메타데이터 확인
4~5주작은 데이터의 첫 MLP, 물리 데모 정리기존 조건에서 학습 가능성 확인, 중간 시연
6~7주조건 확대와 UE 실시간 보정 연결학습에 쓰지 않은 조건의 전체 반응 재생
8~9주오류 보완, 공통 조건의 네 방식 비교품질·시간·메모리와 실패 원인 수집
10주결과 분석, 영상·보고서·재현 절차 정리반복 가능한 데모와 한계가 포함된 결과

원안의 10주를 바탕으로 재배치한 제안입니다. 7~8주에 학습·엔진 문제를 처음 발견하지 않도록 초기 왕복 시험을 앞당겼습니다. 실제 학사 일정·인원별 배분은 미확정입니다.

중간 발표의 물리 프로토타입은 최종 데이터 생성기로 이어진다는 원안의 장점을 유지한다. 동시에 신경망을 마지막에 붙이지 않고 작은 데이터의 학습 가능성을 조기에 확인한다.

개발 판단 기준

가장 먼저 확인할 것은
학습할 만한 반응을 만들 수 있는가입니다

위험확인 방법대응 제안
교사가 부자연스럽다대표 피격을 영상과 관절 로그로 검수물리 추종·감쇠를 조정, 상체·약한 충격으로 축소
한 조건에서도 학습이 안 된다소수 에피소드 과적합 시험좌표계·시점 정렬·회전 표현·타깃부터 점검
본 적 없는 조건에서 튄다보간과 조합 시험을 별도 분석검증한 입력 범위를 명시, 범위 밖은 기존 반응 사용
물리보다 느리거나 차이가 작다전체 처리 비용과 캐릭터 수별 측정입력·관절·모델 크기 축소, 유효 구간과 한계 보고

첫 단계의 결과물

피격 정보를 표시하는 장면, 안정적인 물리 반응 영상, 한 에피소드의 기본/반응 자세 기록, 작은 모델의 엔진 추론 확인을 먼저 확보합니다.

최종 산출물은 데이터 생성기 + 학습 보정기 + 비교 실험입니다.

현재 완료한 것은 연구안 분석과 설명 페이지다. 시연 영상·학습·엔진 검증은 앞으로 수행할 산출물이며 여기서 완료로 주장하지 않는다. 범위 밖 반응을 알려 주는 마법 같은 신뢰도 추정기가 아니라 설정한 범위와 런타임 수치 검사를 기반으로 대체 경로를 둔다.
