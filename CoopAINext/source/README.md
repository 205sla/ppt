# CoopAINext 제작·근거

2026-10-08, 남은 반학기 연구와 응용 방향을 제안하는 26장 HTML 발표자료. 논문 10편과 공식 모델 카드 1개를 확인하고, 그중 9편의 그림을 원문 PDF에서 캡처했다. 핵심 논문은 필요한 본문·그림·실험/한계 부분을 읽었으며 논문 전체 구현을 재현한 결과가 아니다.

## 파일과 재생성

- `../index.html`, `../styles.css`, `../deck.js`: 공개 웹 원본.
- `../downloads/CoopAINext.pdf`: 인쇄용 26쪽. 재판단 장면은 최종 비교 장면, 2×2는 모든 비교 식으로 고정한다.
- `references.json`: 제목·저자·게재 상태·원문 주소·확인일·수집 PDF 해시.
- `capture-manifest.json`: PDF URL·1부터 센 페이지·그림 번호·PDF 좌표·PNG SHA-256.
- `speaker-notes.md`: 장별 설명, 해석의 한계와 발표 순서.
- `analysis.md`: 선택 근거와 연구 설계 판단.
- `author.py`: Python 표준 라이브러리로 HTML/노트용 슬라이드 원본을 생성한다. `python -X utf8 CoopAINext/source/author.py`로 현재 자료 폴더에 다시 쓴다. `index.html`을 직접 바꿨다면 원본에도 반영해야 한다. 이미지·CSS·JS를 재생성하는 도구는 아니다.
- `qa.mjs`: 웹의 그림 확대·시나리오 재생·2×2 선택·인쇄 고정/복귀·1920/1280/844 가로 화면 검증.

저장소 루트에서 `npm.cmd run pdf -- CoopAINext`, `npm.cmd run qa -- CoopAINext`, `npm.cmd run build`로 검수한다. 전역 발표 기능과 다른 자료는 수정하지 않았다.

## 설명의 경계

교수님 발언은 10/2 내부 상담 정리의 요약이다. 새 세부 실험·일정·역할별 작업·응용은 권고안이며 팀 합의나 교수님 직접 지시가 아니다. 연구의 핵심 두 변수는 10/2 확정 주제인 재판단 정책과 행동 AI 학습 여부다. 대화 AI + 행동 AI 두 개, 일반 코드 조정기·기억·실행기 구조를 유지한다.

현재 게임 검증 수치는 main `bd92d2f`의 통합 기록을 근거로 한다. 시험 통과 개수를 과제 성공률로 쓰지 않는다. 이전 Live API 합성 음성 8개와 최신 수정의 검증 범위를 구분한다. 본 작업에서 게임·학습·성능 시험을 새로 수행한 것은 아니다.

실험 효과를 보여 주는 가상 수치·결과 그래프는 넣지 않았다. 시나리오 애니메이션은 설명용 예시다. 약 8주는 상대 일정 제안이며 최종 마감 확정이 아니다. 별도 팀원 메시지·교수님 보고 발송은 하지 않았다.

## 캡처와 출처

모든 그림은 원문 PDF의 필요한 부분을 실제 렌더링한 발췌이며 새로 그린 그림이 아니다. 종횡비를 유지하고 한국어 설명과 원문 링크·페이지·그림 번호를 함께 제시한다. 원본 PDF와 로컬 검수 근거는 학기 자료 폴더에서 보관하며 공개 Pages에는 PDF 논문 전체를 배포하지 않는다.

R6 LoRA는 ICLR 2022 논문이지만 캡처 버전은 공개 arXiv v2다. R10 CoCoBench는 2026-08-28 사전 공개 v1이며 심사 완료 연구로 취급하지 않는다. R11은 공식 Qwen 모델 카드이며 LM Studio 별칭과 학습 원본의 동일성을 새로 검증했다는 뜻이 아니다. 원문 권리는 원저자·발행처에 있고, 개별 재배포 라이선스를 일괄 확인한 것으로 표현하지 않는다.
