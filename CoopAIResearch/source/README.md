# 재판단과 행동 AI 파인튜닝 연구 설명

2026-10-02 사용자가 확정한 연구 방향에 파인튜닝을 포함해 교수님께 설명하기 위한 페이지다. 기존 조정기 주간 발표는 별도 자료로 보존했다.

## 읽는 방식

- 기본 화면은 목차와 16개 장을 연속으로 읽는 문서다. 스크롤과 좌우 키로 이동할 수 있다.
- 퍼즐 협동, 상태 변화, 실행 흐름, 호출 정책, LoRA, 학습 사례와 비교 조건을 자동으로 시연한다. 화면에 읽고 있는 장만 재생한다.
- 페이지 이동·스크롤은 자동으로 하지 않는다. 상단에서 애니메이션을 멈추거나 다시 재생한다. 운영체제의 동작 줄이기 설정도 따른다.
- `N`은 발표자 노트, `F`는 전체 화면이다. 모바일에서는 목차 버튼을 사용한다.
- PDF는 각 장을 정적인 장면으로 저장한 16쪽 자료다. `?print=1`에서 인쇄 준비를 반복해도 같은 결과를 유지한다.

## 내용 기준

연구 한 문장: **DPT-Agent의 실행·추론 분리 구조를 참고해 상황 기반 재판단과 행동 AI 파인튜닝을 적용하고, 협동 성공률·반응 시간·호출 비용을 비교한다.**

1. 대화 AI와 행동 AI만 모델이다. 조정기·기억·게임 필터·실행기는 코드다.
2. 연구 방향은 확정됐지만 실제 팀원 맵·모델 연결, 반복 재판단, LoRA 학습과 네 조건 비교는 예정이다. 모의 검증과 실제 통합을 구분한다.
3. LoRA는 기반 모델을 유지하며 변경분을 학습하는 방법이다. 응답 속도 개선이나 1초 이하 결과를 보장하지 않는다.
4. 고정 주기/상황 기반 × 학습 전/LoRA의 네 조건에서 입력·모델·장비·파트너 등 비교 조건을 고정한다. 고정 주기의 간격도 여러 값으로 검토한다.
5. 학습·개발·시험은 맵, 관계, 전체 플레이 단위로 먼저 나눈다. 인접 상태나 문장 변형이 시험 해법을 학습으로 유출하지 않도록 한다.
6. 자체 제작한 도식은 개념 설명이다. 성능 그래프·개선율·학습 사례 수 등 측정하지 않은 결과를 만들지 않았다.
7. 초기 역할과 일정은 기존 기록을 참고했다. 학습 등을 포함한 세부 배분은 제안이며 팀 조정 대상이다.

## 수정·검증

원고는 `../index.html`, 표현은 `../styles.css`, 자동 시연은 `../deck.js`에서 수정한다. 공용 코드는 변경하지 않았다. 이 폴더의 `qa.mjs`는 자동재생·중지·화면 밖 중지·결과 상태·목차·연속 읽기·인쇄 복원·동작 줄이기·모바일 넘침을 확인한다.

```powershell
npm.cmd run pdf -- CoopAIResearch
npm.cmd run qa -- CoopAIResearch
npm.cmd run build
```

이번 페이지는 게임, 모델, 음성 인식 서비스에 접속하지 않는 정적 설명 자료다. 기반 모델, GPU, LoRA rank와 데이터 규모는 실제 팀 환경 확인 후 연구 기록에서 구체화한다.
