- 배포 위치: `CoopAICoordinator/`. HTML 8장 + 자동 생성 PDF.

## 편집과 발표

`index.html`은 내용·SVG 도형·발표자 노트, `styles.css`는 화면·인쇄, `deck.js`는 두 장의 단계 재생을 관리한다. 공통 슬라이드 이동은 `shared/deck.js`를 사용한다. 방향키로 페이지 이동, F로 전체 화면, N으로 발표자 노트. 2장·4장 버튼으로 각 흐름을 재생한다. 자동 재생은 사용자가 시작하며 다른 페이지나 숨겨진 탭으로 이동하면 멈춘다.

PDF는 전체 시퀀스와 퍼즐의 통과 대기 장면을 보여 준다. 중복 print 준비는 첫 상태만 저장하며 일반 화면 복귀 시 단계 상태를 되돌리고 자동 재생은 재시작하지 않는다. `source/qa.mjs`가 단계 이동, 이탈 시 정지, 완료 조건, 반복 인쇄와 복귀를 검사한다.

## 재사용 범위

사용자 요청에 따라 `_archive/CoopAIFlow`의 `deck.js`에 있던 프레임 배열·단일 재생 타이머·인쇄 대표 장면 패턴과 격자 퍼즐 설명 방식을 재사용했다. 실제 소스는 새 슬라이드 구조에 맞춰 작성했다. 과거 `hold_blue/action_id` 예시, 미완료 상태 흐름, 재판단 옵션은 가져오지 않았다. 새 자료는 현재 계약의 `move_to`, `hold_plate`, `wait`, `accepted → running → completed`와 실제 유지·통과 확인을 기준으로 한다. 원래 보관 폴더는 수정하지 않는다.

## 검증 명령

저장소 루트에서 `npm.cmd run pdf -- CoopAICoordinator`, `npm.cmd run qa -- CoopAICoordinator`, `npm.cmd run build`. PDF의 모든 페이지를 렌더링해 한글·레이아웃·대표 상태를 육안 확인한다. 배포 검증과 버전 정보는 학기 문서의 발표자료 기록에 보관한다.
