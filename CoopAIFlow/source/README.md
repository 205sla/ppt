# 두 AI의 동작 흐름 통합 버전

CoopAI의 1·2·7페이지를 한 장으로 통합한 동적 자료다. 2026-09-19 대화 AI + 행동 AI 두 개의 확정 구조로 개편했다.

## 조작

재생·일시정지, 이전·다음 단계, 처음, 단계 점 선택을 지원한다. 방향키는 단계 이동, Space는 재생, Home/End는 처음/마지막 단계, F 전체 화면, N 발표자 노트다.

‘이동 중 같은 AI에 재판단’을 켜면 추가 목표인 역할 교대를 이미 선택을 완료한 같은 행동 AI가 다음 요청으로 검토한다. 이 동안 기존 유효한 이동·발판 유지는 엔진이 수행한다. 새로운 계획의 채택과 실행은 이 한 장의 범위 밖이다. 별도 계획 모델을 사용하지 않는다.

PDF는 실제 접촉이 확인된 Holding 장면과 두 AI의 역할을 한 페이지에 고정한다. 반복 인쇄 준비는 같은 결과를 내고 인쇄 종료 뒤 조작 상태를 복원한다. 모의 움직임은 실제 성능 측정이 아니다.

## 파일과 근거

index.html, styles.css, deck.js가 화면과 재생을 담당한다. source/qa.mjs는 AI 역할 수, 이동·접촉·음성 회신 순서, 같은 행동 AI의 재판단, 키보드·인쇄 복원을 검사한다. 계약 근거는 `../../CoopAI/source/README.md`와 발표자 노트의 공식 링크를 따른다.

## 2026-09-19 확정 구조

AI 역할은 대화 AI(GPT-Live)와 행동 AI(LLM 한 개) 두 개다. 행동 AI는 다음 행동 선택, 복잡한 계획, 질문·제안, 새 정보에 따른 재판단을 함께 맡는다. 조정기, 기억 저장, 형식·버전 검사와 언리얼 실행기는 일반 코드다. 독립적인 빠른 판단 AI나 느린 계획 AI를 추가하지 않는다.

대화 세션과 행동 AI의 요청, 이미 시작한 유효한 엔진 행동은 독립적으로 진행할 수 있다. 행동 AI 요청은 한 번에 하나를 기본으로 관리하고 새 지시로 낡은 결과가 도착하면 코드가 폐기한다. 여러 로컬·원격 모델은 하나의 행동 AI 자리를 바꾸는 실험 조건이다. 동시에 쓰는 추가 에이전트가 아니다.

API 이벤트 예시는 2026-09-18 공식 자료와 기존 LiveDemo를 대조한 계약을 유지한다. client delegation으로 앱이 한 행동 백엔드를 호출한다. 위임 생성 이벤트는 지시문이 아닌 메타데이터이며 전사·작업 문맥은 앱에서 연결한다. 결과 append의 ACK와 실제 음성 재생·게임 성공을 구분한다.

이 자료는 설계 설명용 모의 재생이다. 새로운 API 추론·언리얼 플레이·모델 성능 측정 결과가 아니다.
