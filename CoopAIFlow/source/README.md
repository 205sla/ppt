# 협력 AI 동작 흐름 통합 버전

원본 CoopAI의 1·2·7페이지를 한 장으로 통합한 별도 동적 자료다. 원본 15장은 그대로 유지한다. 같은 화면에서 음성·게임 상태·빠른 판단·선택적인 느린 계획·명령 검증·실행·결과 회신을 설명한다.

## 조작

- 재생 / 일시정지, 이전 / 다음 단계, 처음, 단계 점 선택.
- 방향키는 단계 이동, Space는 재생, Home/End는 첫/마지막 단계.
- F 전체 화면, N 발표자 노트.
- ‘이동 중 계획도 요청’을 켜면 추가 목표인 역할 교대 방법을 느린 모델이 검토하는 경우를 보여준다. 현재 유효한 이동·유지 행동은 계속한다.

모든 이벤트·작업 ID·좌표·움직임은 설계 설명을 위한 예시다. 실제 모델이나 마이크 API를 호출하지 않는다. 재생 간격은 발표 편의를 위한 값이며 응답 지연의 측정값이 아니다.

## 데이터 해석

음성은 WebRTC 미디어 트랙이다. 전사·위임은 앱의 문맥 구성 재료이고, 위임 생성 이벤트 자체에 지시문이 들어 있지 않다. 전사 delta나 시간 간격만으로 실행을 확정하지 않는다. 현재 게임 상태와 지시 의도를 검사하고 행동을 허용한다.

게임 JSON, task_epoch, operation_id는 앱의 설계 예시다. Holding은 실제 발판 접촉 유지이고 전체 작업 완료가 아니다. 결과를 알려주는 대사는 접촉 확인 후에만 나온다. 느린 계획은 유효한 실행과 별개로 진행하며, 새 계획 채택·추가 행동은 이 한 장의 시연 범위 밖이다.

GPT-Live 계약과 출처는 기존 `../../CoopAI/source/README.md` 및 화면의 발표자 노트를 따른다. 공식 근거는 2026-09-18에 확인한 WebRTC / Live conversations / Live delegation 문서다. 새 API 기능이나 모델 성능을 주장하지 않는다.

## 파일

- index.html: 한 장의 연결 구조, 게임 장면, 발표자 노트.
- styles.css: 원본과 같은 밝은 청록 계열, 16:9 비율.
- deck.js: 단계 상태, 선택적 병렬 계획, 재생과 인쇄 상태 복원.
- source/qa.mjs: 이동·접촉·발화 순서, 계획과 실행, 키보드·인쇄·레이아웃 검수.

PDF는 발판 접촉 장면과 전체 흐름을 함께 보여주는 한 페이지로 고정한다.
